# คู่มือเติมข้อมูลก่อนนำบทที่ 4 และ 5 เข้ารูปเล่ม

ต้นฉบับใช้ชื่อโครงงานและวัตถุประสงค์ทั้งสามข้อที่ผู้จัดทำให้ไว้ เนื้อหาด้านความสามารถระบบตรวจเทียบกับซอร์สโค้ดและเอกสารของ Scopebot เมื่อวันที่ 31 ตุลาคม 2569 ยังไม่ได้ดำเนินการทดสอบระบบหรือเก็บผลจาก NT ในงานจัดทำรายงานครั้งนี้ จึงไม่มีการใส่คะแนนความแม่นยำ เวลาเฉลี่ย คะแนนความพึงพอใจ หรือผลผ่านการทดสอบขึ้นเอง

## การเปิดและจัดรูปเล่ม

- เปิด research-chapters-4-5.html ด้วย Microsoft Word แล้วเลือกบันทึกเป็น Word Document (.docx) หรือเปิดในเบราว์เซอร์เพื่ออ่านต้นฉบับ
- ไฟล์ HTML ใช้รูปแบบตัวอักษรภาษาไทยและหัวข้อสำหรับแก้ไขต่อ ยังไม่ได้ตรวจการแบ่งหน้าใน Word และไม่ใช่ไฟล์ DOCX
- ปรับฟอนต์ ขนาดตัวอักษร ระยะขอบ การย่อหน้า และเลขหน้าตามคู่มือมหาวิทยาลัย ฟอนต์ที่กำหนดในต้นฉบับคือ TH Sarabun New และมี Tahoma เป็นตัวสำรอง
- ย้ายข้อความเข้ารูปเล่มหลังบทที่ 3 แล้วปรับชื่อหัวข้อให้ตรงกับสารบัญเดิม
- ใช้ไฟล์ Markdown เมื่อต้องการแก้ไขเนื้อหาเป็นข้อความธรรมดา

## ข้อมูลที่ต้องเติม

1. สภาพแวดล้อมที่ใช้จริง โดยเฉพาะชื่อโมเดล ฐานข้อมูลเวกเตอร์ และรุ่นเอกสาร ห้ามใช้ค่า default ในโค้ดแทนค่าที่รันจริง
2. ชุดคำถามพร้อมคำตอบอ้างอิงและตำแหน่งหลักฐานในเอกสารของ NT ที่ได้รับอนุญาต
3. ผลทดสอบรายกรณีในตารางที่ 4.3 พร้อมวันทดสอบและหลักฐาน
4. ผลตรวจคำตอบและแหล่งอ้างอิงในตารางที่ 4.4 แล้วจึงคำนวณค่าร้อยละตามตัวหารที่ระบุ
5. ผลตรวจความครบถ้วนของประวัติในตารางที่ 4.5 โดยระวังการนับรอบที่รับช่วงสนทนาซ้ำกับช่องทางต้นทาง
6. ภาพหน้าจอจริงตามเครื่องหมายแทรกรูป และกราฟรูปที่ 4.14 เมื่อมีข้อมูลจริงแล้ว
7. ข้อสรุปท้ายบทที่ 4 และหัวข้อ 5.1, 5.2.1, 5.3.5 และ 5.6 ให้สอดคล้องกับผลทดสอบ ห้ามสรุปว่าบรรลุทุกข้อหากหลักฐานยังไม่ครบ

ข้อความส่วน 4.5 เป็นโครงสำหรับเติมผลจริง หากบทที่ 3 กำหนดวิธีทดสอบไว้แล้ว ให้ใช้เกณฑ์จากบทที่ 3 และปรับข้อความเชิงวิธีการในบทที่ 4 ให้กระชับหลังได้ผล ไม่จำเป็นต้องเพิ่มการประเมินความพึงพอใจหากไม่ได้อยู่ในขอบเขตโครงงาน

ก่อนส่งรูปเล่ม ให้ค้นหาเครื่องหมาย “[เติม” และ “[แทรก” ทั้งหมด เติมข้อมูลหรือแทนด้วยภาพจริง แล้วลบคำแนะนำในวงเล็บเหลี่ยม โดยคงคำบรรยายภาพไว้ หากไม่มีข้อมูลสำหรับหัวข้อใด ให้รายงานข้อจำกัดตามจริงหรือปรับหัวข้อให้เหมาะสม ไม่แทนช่องว่างด้วยผลสมมติ

## รายการภาพที่ต้องเตรียม

| รูป | ภาพที่ใช้ | จุดสำคัญ |
| --- | --- | --- |
| 4.1 | แผนภาพภาพรวมระบบ | เว็บไซต์และ LINE เชื่อมบริการกลาง ฐานข้อมูล และ RAG |
| 4.2 | หน้าเข้าสู่ระบบและสถานะบัญชี | ใช้บัญชีทดสอบ |
| 4.3 | หน้ารายการบอท | ชื่อ สถานะ และฐานค้นหา |
| 4.4 | คลังเอกสารและการผูกกับบอท | ใช้ไฟล์ที่เผยแพร่ได้ |
| 4.5 | สถานะประมวลผลเอกสาร | ก่อนและหลังฐานความรู้พร้อม |
| 4.6 | คำถามและคำตอบบนเว็บพร้อมหลักฐาน | แสดงชื่อไฟล์ เลขหน้าเมื่อมี และข้อความต้นฉบับ |
| 4.7 | คำถามที่ไม่มีข้อมูล | แสดงคำตอบหรือการส่งต่อที่เกิดขึ้นจริง |
| 4.8 | การตั้งค่า LINE OA | ปิดบัง token และ secret |
| 4.9 | การสนทนาบน LINE | แสดงคำถามและคำตอบจริง |
| 4.10 | หน้ารวมแชท | เห็นข้อมูลจากทั้งสองช่องทาง |
| 4.11 | ประวัติย้อนหลัง | ภาพย่อยเว็บและ LINE |
| 4.12 | การส่งต่อผู้ดำเนินงาน | เห็นสถานะและลำดับข้อความ |
| 4.13 | แดชบอร์ด | ระบุช่วงเวลาและที่มาของข้อมูล |
| 4.14 | กราฟผลตรวจคำตอบ | สร้างหลังได้ผลจริงเท่านั้น |

บทที่ 5 ไม่จำเป็นต้องเพิ่มภาพหน้าจอซ้ำ ใช้อ้างถึงผลในบทที่ 4 เพื่อให้เนื้อหามุ่งสรุปและอภิปรายผล

## แหล่งตรวจสอบภายในโปรเจกต์

รายการนี้ใช้ตรวจสอบที่มาของคำอธิบายระบบ ไม่ใช่บรรณานุกรมงานวิจัยภายนอก

- README.md และ package.json: ภาพรวมระบบและเทคโนโลยี
- api/auth.py และ api/models.py: บทบาท ขอบเขตข้อมูล บอท เอกสาร และบทสนทนา
- api/routers/documents.py: นามสกุลไฟล์ที่รองรับและการจัดการเอกสาร
- api/routers/dashboard.py: ความหมายของอัตราการตอบสำเร็จ
- src/app/components/chat/ChatView.tsx: การแสดงชื่อเอกสารและเลขหน้า
- src/app/components/admin/SearchHistory.tsx: ประวัติแยกตามบอทและข้อมูลช่องทาง
- docs/semantic-search.md และ docs/rag-correctness.md: การค้นหา บริบทคำถาม และการตรวจหลักฐาน
- docs/knowledge-updates.md: การเผยแพร่ฐานความรู้และการปรับปรุงเอกสาร
- docs/chat-stability.md: ขอบเขตการยกเลิกคำขอและการรับเหตุการณ์ LINE
- docs/qdrant-trial.md: การเลือกฐานค้นหาและข้อจำกัดการเทียบ local กับ server
- test/test_review_fixes.py และ test/test_rag_correctness.py: ตัวอย่างเงื่อนไขที่มีชุดทดสอบรองรับ ไม่ใช่หลักฐานว่าทดสอบผ่านในการจัดทำรายงานรอบนี้

ไม่มีการอ่านข้อมูลลับจาก .env ไม่เปลี่ยนโค้ดระบบ ไม่รัน migration และไม่แก้ไขข้อมูลจริงเพื่อจัดทำต้นฉบับนี้
